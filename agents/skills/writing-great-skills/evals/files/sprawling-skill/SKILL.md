# Summarizing Notes

Summarize the notes carefully. Be thorough and make sure the summary is good.

## Instructions

1. Read the notes.
2. Understand all the notes before continuing.
3. Summarize the notes clearly.
4. Be concise, but also include all useful detail.
5. Make the result high quality and useful.
6. Check that the summary is good.

Always preserve important information. Never omit important information. Make sure important details are included.

## Additional guidance

The summary should be clear. It should not be unclear. Organize it well and use good formatting. If there are multiple themes, summarize the themes. If there is only one theme, summarize that theme.

Be accurate. Do not be inaccurate. Review your work before finishing.
